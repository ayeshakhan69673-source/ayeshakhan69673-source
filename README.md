## 🚀 Featured Projects

### 🎓 [QalamAid](https://qalamaid.vercel.app) — Scholarship Facilitation Platform
My final-year project, built from scratch with a teammate. It connects verified Pakistani students with donors and routes payments directly to universities.
- Secure authentication with **JWT and bcrypt**, plus a 4-step OTP password reset
- University verification through **one-time, 48-hour expiring UUID tokens**
- Custom **Easypaisa sandbox simulator** (7 screens with an OTP flow)
- **AI scholarship assistant** powered by the Google Gemini API
- Contact form and internship application with email delivery
- Deployed on **Vercel** with a cloud **MySQL (TiDB)** database

**Stack:** Node.js · Express · MySQL · JWT · bcrypt · Nodemailer · Multer · Gemini API · Vercel
[Live demo](https://qalamaid.vercel.app) · [Source code](https://github.com/tahabutt01/QalamAid)
